grpc-call

Makes a unary call to any gRPC server that exposes server reflection, resolving the request and response shape at runtime. No generated stubs required.

Maintainer platform-teamPublished Sep 21, 2026Address localhost:9305Serving

Config schema · with:3 required · 5 optional
FieldTypeDescription
addressstringrequiredTarget server as host:port. Resolved through the gateway when it matches a Fuse route.
servicestringrequiredFully qualified service name, e.g. examples.crud.v1.CrudService.
methodstringrequiredMethod on that service. Only unary methods are supported.
requestobjectoptionalRequest message as JSON. Values can reference earlier steps with ${steps.<name>.body.<field>}.
metadataobjectoptionalgRPC metadata sent as headers.
expectobjectoptionalAssertions on status and body. The step fails when any assertion fails.
timeoutdurationoptionalPer-call deadline. Default 5s.
tlsbooleanoptionalUse TLS for the connection. Default false.
Use it in a workflow
- name: query-name
  uses: foundry://grpc-call@v1
  with:
    address: localhost:9090
    service: examples.crud.v1.CrudService
    method: Read
    request: { id: ${steps.create-name.body.id} }
  expect:
    status: OK   # optional
