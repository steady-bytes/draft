Primary
v0.1 · one system for every Draft surface

Circuit board, not dashboard.

Dark first, monospace for anything that is data, thin rules instead of shadows, and color only where it means something. Every token below ships in draft.css as a CSS variable and as a daisyUI 5 theme, so existing btn, badge and table markup picks it up.

02 · Meaning

--primarySwatchable. Active, focus, live
--caCatalyst · also info, links in data
--bpBlueprint · agents
--fsFuse
--svGeneric service
--warnDegraded, medium priority

Rule of thumb: healthy is the quietest state on screen. A running service is a small dot, not a green block; color is spent on things that need a human.
